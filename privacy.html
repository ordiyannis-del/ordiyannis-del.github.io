Privacy Policy

Last updated: October 20, 2026

Auto Clips Studio runs only on the owner's computer.

Data used

The tool uses TikTok Login Kit to obtain an access token for the owner's own TikTok account, and the Content Posting API to upload videos to that account. It reads basic account information (user.info.basic) only to identify the connected account.

Storage and sharing

The access token is stored locally on the owner's computer. It is never shared or sent to any third party. The tool does not collect, sell or share any personal data. Videos are processed locally, and temporary files are deleted after publication.

Revoking access

Access can be revoked at any time in the TikTok app: Settings and privacy, Security and permissions, Apps and services.
